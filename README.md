# Contact Navigator

A premium Flutter application for advanced contact management with integrated interactive mapping and navigation.

## 🚀 Key Features
- **Multi-Location Support**: Save multiple addresses per contact.
- **In-App Navigation**: Calculate driving routes using OSRM directly on the map.
- **Interactive Mapping**: Visual pins for all your contacts with real-time GPS sync.
- **Dynamic Grouping**: Organize contacts into customizable categories.
- **T9 Dialer**: Smart keypad with predictive search.

## 🛠️ Getting Started
1. Clone the repository.
2. Run `flutter pub get`.
3. Ensure location and contact permissions are granted.
4. Run `flutter run`.
